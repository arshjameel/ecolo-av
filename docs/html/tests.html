Written 15 October 2026, checked 25 October, for the team: every test from our talks, in one place, in the order to run them. Each one says what it proves, how to run it, and when it passes.

The short version - Five stages, safest first: the simulator, the bench, the car on stands, the car in an empty lot, then the whole drive. - Never skip a stage: a test only runs once the stage before it passes. - Status: ✅ exists and passes; 🔧 exists, not yet run on the car; ⬜ still to build. - On the car, always: a safety driver, the e-stop in someone's hand, and a speed cap.

Stage 1: the simulator (Gazebo and the turtle)

Nothing real moves. Run these on any laptop.

1.3 The roof lidar pixi run sim-check (on by default) 1800 × 16 rays at 10 Hz in lidar_link ✅

1.6 The HUD, with pretend data pixi run hud-demo the window opens with speed, camera, GPS, e-stop ✅ Ben, 15 Oct

1.9 "SIMULATED" on the HUD run Gazebo, look at the HUD an orange SIMULATED banner; REAL / SIM tag per sensor ✅ built 15 Oct (its logic tested); not yet seen on a screen

1.11 The lidar alone stops the car pixi run sim-check --lidar-obstacle (and --plan-around: Nav2 drives round a box it sees) radar off: stops 0-2 m before a person-sized post, which shows in the local costmap; drives on when it's gone ✅ 15 Oct: 0.16-0.55 m before it
1.12 Sensor failures on purpose pixi run sim-check --faults (--no-watchdog: what happens without the watchdog) each of 13 faults (GPS lost, NaN, jump; IMU stopped, frozen, NaN; wheels stopped, frozen, NaN; camera frozen; radar stopped; the watchdog hung, killed) stops the car within 6 s (frozen wheels: 10 s from when they go wrong), and says why; normal driving never trips the wheels' cross check ✅ 15 Oct: all 13; 24 Oct, with the HUD's heartbeat: all 25 checks, 3 runs of 3
1.13 The spine in the loop pixi run sim-check --spine in Gazebo with spine:=true: the normal checks pass; ego's commands stopped → the spine brakes fully within 0.28 s and latches; /safety/estop and the hardware e-stop → brake within 0.15 s, latched until armed again; disarmed → no motion ✅ 15 Oct: full brake 195-209 ms, e-stops 1-12 ms
1.14 Drive to a GPS point, smooth stop pixi run sim-check --drive-to-point (A to B) every stop within 2 m of B by Gazebo's truth, no overshoot, braking about half max_brake; a cancel, the e-stop and a GPS fault stop it ✅ 15 Oct: all within 0.4 m
1.15 Ghost obstacles: a pretend person only Nav2 sees pixi run sim-check --ghost (docs) a ghost 15 m ahead (nothing in Gazebo): stops 0-2 m before it (the stop zone or the controller), the local costmap marks it; drives on once it's off ✅ 16 Oct: 0.21 m before it, the stop zone fired (one run, radar and lidar on too)

Stage 4: the car in an empty lot

Before: stage 3 passed; the timeout fix (3.9) in; a safety driver; walking pace first. The test script (pixi run actuator-test <test>, docs) logs the IMU (g), the wheel speed, the pose and the GPS for every test.

4a. Speed up, coast, brake

# Test How Measure Status
4.1 Speed up from still, a fixed throttle (25%, 50%, full), 10 m. actuator-test speed-up: a speed command, so the speed loop picks the throttle acceleration in g (IMU), and the time to 1, 2, 3 m/s 🔧
4.2 Coast at 2 m/s, let go: no throttle, no brake. actuator-test coast (with the spine; not the ESP32) how fast it slows: rolling resistance and drag 🔧
4.3 Brake at 1, 2, 3 m/s, a fixed brake (50%, full). actuator-test brake: a normal stop, as no brake command exists stopping distance and deceleration in g 🔧
4.4 Throttle map repeat 4.1 at several throttles; actuator-test throttle-map a table: throttle % → acceleration; and the deadband (the throttle where it starts to move) 🔧

4b. Steering on the ground

# Test How Measure Status
4.5 Circles a fixed steering command at 1 m/s, a full circle each, both ways, several angles; actuator-test circles the circle's size (GPS, or a tape), and yaw rate ÷ speed (IMU): the real wheel angle for each command 🔧
4.6 Tightest turn full lock, both ways (the last pair of actuator-test circles) the turning circle: checks max_steering_angle 🔧
4.7 Straight line steering straight, 10 m at 0.5 m/s; actuator-test straight sideways drift: under 0.5 m over 10 m 🔧

4c. The car's weight (audit M7)

# Test How Gives Status
4.8 Scales 4 bathroom scales, one under each wheel, add them up the mass, ±2%: the best way ⬜
4.9 Speed up twice test 4.1 at full throttle, alone, then with a person of known weight (say 80 kg) mass = 80 × a2 ÷ (a1 − a2), ±10-15%; and the motor's force ⬜
4.10 Brake twice test 4.3 at full brake, alone, then with the same person the mass again; and the braking force ⬜

For 4.9 and 4.10: the same battery charge, the same spot and direction, three runs each, and the coast-down (4.2) subtracted, so drag doesn't count as motor or brake.
