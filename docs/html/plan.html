Written 22 October 2026 from the team's proposal, "Ecolo: an open, closed-loop autonomous vehicle platform" (version 4, the team draft for 23 October). Ben: "Turn that document into a todo list that we can work through", and "we do want to put mppi in there too".

The task numbers (T1.1 ... T9.8) are the proposal's, so the same numbers work in the issue tracker. Only the MPPI track (M1-M9) is new. The 15 October plan's S and C items are at the end, mapped to these numbers.

The short version - Software, built and tested in simulation: about 43% of the committed tasks. Proven on the car: about 5% (the audits). - Ahead: the drivers, ego, the muxes, Gazebo, Nav2, A to B, the HUD. Behind: everything that needs the car or new parts: power, calibration, the closed loop. - Next gate, 30 Oct (Know the car): the car isn't measured yet. That's the most urgent job. - MPPI: Nav2's default since 22 Oct, tuned for the car in Gazebo, and compared with Regulated Pure Pursuit by pixi run controller-compare (controller:=rpp for the old one; controllers). It steers round an obstacle the sensors see. - Status: ✅ done · 🧪 done in simulation only · 🔧 started · ⬜ not started · 🎯 stretch.
