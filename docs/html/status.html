Where things stand on 18 November 2026. Each row carries the date of its last run: a row dated October hasn't been run again unless it says so. The newest work is in Since 16 November; the older "Next" lists are in the status log.

Word Means
"Works" it ran under ROS 2 Jazzy through Pixi: on oirp-spss (Linux), and since 10 October on Ben's Mac too
"On the bench" Bench mode: the car's own software, with stand-ins for the hardware
"In Ravensim" pixi run sim, the default since 8 Nov (Ravensim)
"In Gazebo" every sim run before 8 Nov, and simulator:=gazebo until it was removed on 16 Nov (Gazebo, as it was)
"Untested" the code and its config exist, but it hasn't run yet

The work left is in TODO.md and The plan.
