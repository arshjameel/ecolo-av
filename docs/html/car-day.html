Written 24 October 2026, for the team. Ben, 24 Oct: "Lets get everything prepared so the only thing left is to get into the car." Everything that can be done without the car is done or built; this page is the rest, in order.

The short version - Before you leave: pixi run car-day-build, then pixi run car-day-check until it says 0 missing. - At the car: ten sessions, in order. Each says who, how long, what to bring, the commands, what you should see, and what to do if not. - Wheels off the ground all day. Nothing drives on the ground. - 🔒 = waits on the hardware lead's answer (session 3). Skip it until then, and go on. - Stop at each stop point. Something failed? Write it down, then go to the next session that doesn't need it. - Secrets: the logins are in Ben's Mac's Keychain. Type them; never paste them into a file, a chat or the repo.

Step 6: Cyclone uses one network card

Cyclone DDS (our ROS messaging) picks one network card. With the phone's hotspot on WiFi and the car on the dongle, it may pick the wrong one (Your Mac). Plug the dongle in, find its name (ifconfig: the one that appears, such as en7), and write this file with that name:

<!-- ~/.config/aav/cyclonedds-car.xml: copy it to cyclonedds.xml at the car -->
<CycloneDDS xmlns="https://cdds.io/config">
  <Domain id="any">
    <General>
      <Interfaces>
        <NetworkInterface name="en7"/>
      </Interfaces>
    </General>
  </Domain>
</CycloneDDS>

Keep it as cyclonedds-car.xml at home: a card named in cyclonedds.xml that isn't there stops every ROS program. At the car: cp ~/.config/aav/cyclonedds-car.xml ~/.config/aav/cyclonedds.xml; at home again, rm ~/.config/aav/cyclonedds.xml.

# Do Expect
1 Power on, nothing else brake full (3500), steering centred (1950), DAC 0 V; mode=Manual, faults=0x0000
2 Unplug a Jrk's I2C, plug it back red LED; fault 8 (steering) or 16 (brake) while out
