The software for Carleton's autonomous car: a ROS 2 Jazzy workspace, plus the firmware for the microcontroller that drives the actuators. These pages explain how it fits together, and how to run it.

The whole stack in one picture

Read it top to bottom: sensors become telemetry, drivers become one command, and ego moves the car.

Step What happens
1. Sense Sensors publish raw data. Two filters (EKFs) work out where the car is.
2. Propose Each driver proposes a speed and a turn rate: joystick, keyboard, script or navigation (a route, a plan, a path follower).
3. Pick twist_mux passes on the highest-priority driver. /safety/estop blocks them all.
4. Convert ego, the virtual car, turns that into a speed and steering angle the car can do.
5. Move One backend moves something: the real car, Ravensim (our simulator), CARLA, or a turtle on the screen.

Try it in five minutes

The full hour, with rqt_graph, Ravensim and a goal, is Your first day. On a Mac or on Linux, once pixi is installed:

pixi run build       # compile our packages
pixi run turtle      # terminal 1: a turtle that steers like the car
pixi run keyboard --local    # terminal 2: hold i to drive, u or o to turn
