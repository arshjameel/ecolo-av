Every ROS package in ros/, area by area (ros/<area>/<package>), with what it reads and writes. Then the firmware, the HUD and the examples. 72 packages build with colcon today (counted 18 Nov; the Flask HUD went to the archive on 25 Oct), and none is parked. Two more folders are plain Rust programs, built with cargo: aav_dev_window and aav_sim_cameras. The newest packages (30 Oct to 18 Nov) are in the first table only: each one's README has its topics.

"Gazebo" in a status means it was tested there, before Gazebo went on 16 Nov. Ravensim, our simulator, has the same topics; a status says "Ravensim" once re-run there.

Backends

Each backend reads ego's commands from the output mux (/control/<target>/actuator_cmd) and reports the car's speed on /vehicle/odom. Only one runs at a time.

Package Plays the car with Also

aav_legacy UART frames to today's ESP32 (/dev/ttyAMA0): 13 bytes today, or version 2 (17 bytes) with the output mux's heartbeat encoder_udp: the 2025-26 wheel encoder's UDP packets into /vehicle/odom (off on the car since 23 Oct: the wheels are on CAN)
